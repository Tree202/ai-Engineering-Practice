# 六条版式规则

每个模块暴露 `check(path, html) -> list[dict]`，由 `../check_layout.py` 驱动。
模块只用标准库，可以单独 `python det_xxx.py` 运行自测。

| 模块 | 抓什么 | 真值验证 |
|---|---|---|
| `det_dangling_node.py` | SVG 里有入边、没出边的非终止节点 | 原版 01 页报出 5b/5c/兜底 三条，已修版 0 条 |
| `det_dangling_edge.py` | 箭头端点附近没有任何节点 | 原版 01 页报出那条停在方框外 10.8px 的箭头 |
| `det_grid_text.py` | grid/flex 容器里混有裸文本节点 | 原版 02 页报出 `.chk li` 七条，已修版 0 条 |
| `det_overflow.py` | 元素坐标跑出 viewBox | 复刻 14 页历史缺陷（y=530 vs 画布高 524）精确报出 |
| `det_collision.py` | 文字压别的方框、方框互相重叠 | — |
| `det_refs.py` | `url(#id)` 指向不存在的 marker、重复 id | — |

**调参不是拍脑袋定的。** 例如 `det_dangling_edge` 先统计了已修版 23 页全部 95 个
带箭头端点到最近节点的距离。其中 **2 个**（00/01 页时间轴那两条，端点离最近节点 47.0px、
另一端离最近节点 63.3px）被「另一端必须贴住某个节点」那条判据挡在判定之外；
**参与判定的 93 个**分布是 0px×28、2px×9、4px×49、6px×6、8px×1，最大值正好 8.0px，
而真值缺陷是 10.8px 且垂直偏移 10px —— 容差 8px 卡在 8.0 与 10.8 之间。
（复算法：`sys.path` 加上本目录后 import `det_dangling_edge`，用它自己的 `SvgScan`
解析 23 页，对每条带 marker 的边的那一端算到最近节点包围盒的距离，按 2px 分桶。
上一版这里只列到 93，漏掉的正是那 2 个 —— 结论不受影响，但推导写得不准。）
`det_overflow` 做了变异测试：画布砍 8px 一条不报、砍 40px 全部报出。

**驱动层还做了三处规则收窄**，每一处都由一次对抗复核的证据推出来，
见 `../check_layout.py` 里 `收窄()` 的注释。那是收窄判据，不是白名单。

## 自测本身也要能失败(第三轮补上)

此前六个模块的自测**有输出、没退出码**：`_selftest()` 裸调，打印 `FAIL` 也返回 0，
`det_dangling_edge` 更是硬写 `sys.exit(0)`。等于「跑了自测」只是一句话。
现在统一为 `sys.exit(_selftest())`，并逐个用变异验证过：
把 `check()` 改成恒返回 `[]`（正是真值门槛要拦的那种「永远零问题」的检查器），
**六个模块全部 exit=1**。

样本路径也不再写死作者机器的绝对路径，改为 `_baseline.py` 统一解析：
`AIWF_BASELINE` → 仓库同级 `ai-workflow/` → `fixtures/baseline/`（随仓库发布的快照）。
缺样本时明说「跳过真值段 —— 不算通过」，不再静默返回 0。

## 已知盲区:终点列判据

`收窄()` 里的 `_终点列` 会豁免「最右一列且该列有 2 个以上节点」的无出边节点。
第三轮对抗核验指出旧写法只比**右边缘**，于是一条右缘贴齐画布的通栏矩形
就能和右列节点凑成「同列 2 个」，把单个真断开的节点整条吞掉。
实测：往真值样本注入这样一条矩形，旧判据 3 条 → **2 条**。

现已改为左右边缘都要对齐，并在 `真值自检()` 里加了一条**变异锁**固化这个场景。
但盲区仍在：**两个真断开的节点若同在最右一列且左右都对齐，依旧不报。**
这是判据的设计边界，不是 bug —— 记在这里，不假装没有。

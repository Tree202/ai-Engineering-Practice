Claude Code 初学者知识库

这份知识库回答一个问题：「我每次都要粘贴同一段长提示词，有没有更好的办法？」
从提示词该怎么写开始，一路讲到把它拆成技能、输出风格、CLAUDE.md 和模板， 最后动手做出一条属于你的 /kb 命令。

📖 怎么用这份知识库

时间紧 → 只读 01 → 02 → 05 → 07 这条主线，约 40 分钟，足够动手了。
05 会用到 04 的「输出风格」概念，那一章开头有一句话的提要，不读 04 也跟得上。
想学透 → 按 01 到 07 顺序读完。
只想解决某个具体问题 → 看下面的问题速查表。

右上角可以切换浅色 / 深色 / 跟随系统三种主题，默认深色，你的选择会被记住。
